# Contributing to Courier

Courier values correctness, clarity, and restraint.

## Guidelines

- Keep APIs small and explicit
- Avoid cleverness
- Prefer boring, readable code
- Preserve default performance characteristics
- Add capabilities instead of conditionals

## Pull requests

PRs should:

- Include tests
- Preserve default array row behavior
- Avoid introducing implicit behavior
- Document new capabilities or hints

## Code style

- TypeScript-first
- No unnecessary abstractions
- Explicit error handling
